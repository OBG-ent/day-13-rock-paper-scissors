# 🪨📄✂️ Rock Paper Scissors

**The classic showdown — you vs the computer, first to 5 wins the match.**

Click 🪨, 📄, or ✂️ and the CPU fires back instantly. The arena shows both picks side by side, the scoreboard tracks the match, and a verdict banner declares the winner at 5 points.

## ✨ Features

- Live scoreboard (You vs CPU) with round counter
- Animated arena showing both picks each round
- Round-by-round result messages ("Rock beats scissors — you score!")
- First to 5 points wins, with a match verdict banner
- One-click "New match" reset

## 🚀 Run it in 30 seconds

No build step, no dependencies — it's three static files:

1. Open `index.html` in any browser (double-click it, or drag it into a tab).
2. Pick rock, paper, or scissors. That's it.

## 🧠 What I practiced

- Event listeners on multiple buttons
- Lookup tables (`BEATS`, `EMOJI`) instead of long if/else chains
- Game state management (score, round, match-over flag)
- Updating the DOM to reflect state after each round
- Random move selection with `Math.random()`
